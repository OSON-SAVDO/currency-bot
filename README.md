# Telegram Currency Bot 🤖

Ин боти Телеграм курсҳои асъор (USD/RUB ва RUB/TJS) дар вақти воқеӣ пайгирӣ мекунад ва дар ҳолатҳои зерин ба шумо хабар медиҳад:
- Тағйирёбии назарраси курс (1 рубл боло ё поён рафтан).
- Санҷиши худкор ва ҳимоя аз хоб рафтан дар Render (Keep-Alive).
- Фармонҳои фаврии `/start` ва `/kurs`.

### Файлиҳои лозима:
- `bot.py` - Коди асосии бот
- `requirements.txt` - Китобхонаҳои лозима
- `Procfile` - Танзимоти кори бот дар сервер
